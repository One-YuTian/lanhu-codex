# 蓝湖插件安装与使用

## 安装到 Codex 插件市场

1. 安装 Node.js 20.19 或更高版本。macOS 使用 nvm 时，请设置已安装的默认版本，例如 `nvm alias default 20`。
2. 打开 Codex 的插件市场，选择添加市场，填写本仓库地址：
   ```text
   https://github.com/One-YuTian/lanhu-codex.git
   ```
3. 在「蓝湖插件市场」中找到「蓝湖」并安装。
4. 打开蓝湖面板，点击「填写 Cookie」，粘贴从蓝湖网站取得的 Cookie，点击「保存并校验」。
5. 校验成功后会自动进入项目管理。选择团队，双击项目即可打开；也可以通过蓝湖链接导入项目。团队及最近打开的项目会自动保存，最近项目最多显示 8 条；刷新或下次打开时恢复原项目页面，显式指定项目时优先使用指定项目。

如果当前 Codex 版本不支持在界面中添加市场，请先更新 Codex。安装过程使用仓库默认分支上的版本。

## 更新插件

1. 在 Codex 插件管理中找到「蓝湖插件市场」，刷新市场并检查「蓝湖」的更新。
2. 安装可用更新后，关闭蓝湖面板并重新打开；必要时重启 Codex。
3. 如果仍使用旧版，可从同一市场卸载后重新安装。重新打开时如提示填写 Cookie，请按下方步骤获取并校验。

仅下载源码或修改本地文件不会更新 Codex 已安装的插件。确认市场指向上方仓库，并已发布所需版本到市场实际使用的分支。

macOS 如果插件安装后面板不显示，请确认已安装 Node.js 20.19 或更高版本，使用 nvm 时已设置默认版本，并更新到 0.2.2 或更高版本。0.2.2 修复了宿主插件数据目录过长时，面板关闭后无法重新连接的问题。

## 获取蓝湖 Cookie

1. 用 Chrome 或 Edge 打开 [蓝湖](https://lanhuapp.com/)，登录自己的账号并进入团队或项目页面。
2. 按 `F12` 打开开发者工具；macOS 也可以按 `⌘⌥I`，Windows 可以按 `Ctrl+Shift+I`。
3. 切换到 **Network（网络）**，选择 **Fetch/XHR**，刷新页面。
4. 选择一条发往 `lanhuapp.com` 的接口请求。在 **Headers（标头） → Request Headers（请求标头）** 中找到 `Cookie`。
5. 复制 `Cookie` 的完整值，格式类似：
   ```text
   user_token=…; other_cookie=…
   ```
   只复制值，不要包含 `Cookie:` 前缀、换行、请求命令或完整请求头。
6. 返回 Codex 蓝湖面板，点击「填写 Cookie」，粘贴后选择「保存并校验」。校验成功会直接进入项目管理，不会新建登录对话。

Cookie 相当于登录凭据，请只填入自己的蓝湖插件，不要发到聊天、截图、公开仓库或分享给他人。如果提示 Cookie 无效或登录过期，请重新登录蓝湖网站，再复制最新 Cookie。网络或项目权限错误需要先检查网络、团队和项目访问权限。

## 图片压缩

调用 `lanhu_compressed_picture` 打开内联面板。点击左侧添加图片图标，用系统文件选择器多选 JPG/JPEG/PNG/WebP。不支持拖入、添加目录或补选原图路径。设置图标位于添加图片之后，弹窗可设置自动开始（默认是）和并发数（默认 5，范围 1–20），设置保存到本机。

右侧依次提供独立的全部清空、清空成功、重试、开始、暂停图标，按任务状态禁用。重试只处理失败项，开始只处理待处理项；每行亦可单独重试。暂停阻止后续任务开始，已开始的任务完成下载和安全替换。清空成功移除已完成、无收益跳过的列表项；全部清空及清空成功均不删除磁盘图片。

图片上传至第三方 TinyPNG，单张最大 5,200,000 字节。参考 [super-tinypng](https://github.com/zhanyuzhang/super-tinypng) 为每个请求设置随机 `X-Forwarded-For`；第三方接口拒绝或限制时显示错误，不自动无限重试。列表含缩略图、原始/压缩后大小、节省比例与状态，整行背景显示进度，右上角图标之前显示已结束/总数。

完整下载并校验后，通过同目录临时文件写入、刷新及原子重命名同名替换；替换前检查原图是否被外部修改。失败或无体积收益时保留原图，临时文件在提交或失败后自动清理，清理异常明确报错。硬链接和符号链接不原地替换。`lanhu-compressed-picture` SKILL 亦支持已授权的工具批量工作流。
